# 變更歷史邏輯: ChangelogLogic

## 目的

- 欄位異動的唯一歷史來源，任一時點的欄位狀態皆可重建
- 燃盡圖以重建結果取得任一日的剩餘工作量
- 週期時間與卡關分析取狀態停留時長
- 基準線追蹤回答工單延期次數與滑動天數

---

## recordFieldChange 寫入欄位異動

- 追蹤開關為真的欄位，每次異動寫一列
- **輸入:**
  - 工單識別
  - 異動欄位的名稱、舊值、新值
  - 執行者
- **逐欄寫列:**
  - **執行:**
    - 一次儲存異動多個欄位時，逐欄各自執行本子操作
    - 讀取異動欄位的欄位定義，取追蹤開關
    - **IF** 追蹤開關為假:
      - RETURN
    - **ELSE:**
      - 於該工單的 ChangeLog 追加一筆記錄
      - 單筆內容含欄位名、舊值、新值
      - 單筆的作者記執行者，時間記寫入當下
- **追蹤範圍宣告:**
  - **行為:**
    - 記錄範圍由欄位定義的追蹤開關宣告，不逐張工單決定
- **寫入保護:**
  - **行為:**
    - ChangeLog 僅由系統寫入
    - 使用者不可編輯或刪除任何一筆記錄
- **保留規則:**
  - **行為:**
    - 保留期限不設上限，不自動封存

---

## rebuildFieldStateAt 重建時點欄位狀態

- 以變更歷史重放，取得任一時點的欄位值
- **輸入:**
  - 目標時點
  - 工單範圍
  - 欄位範圍
- **性質:**
  - 純讀取，不改動任何資料
- **執行:**
  - 取不晚於目標時點的 ChangeLog 記錄
  - 依時間由舊到新排序
  - 逐欄取最後一筆的新值，作為該時點的值
  - **IF** 某欄位於目標時點前無任何記錄:
    - 該欄位於該時點視為尚無值
- **回傳:**
  - 各工單各欄位於目標時點的值
