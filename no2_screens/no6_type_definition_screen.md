# 型別定義: TypeDefinitionScreen

## 畫面目標

- 管理欄位組、欄位定義，與工單型別的欄位組配方

---

## 線框圖

```text
頁籤：欄位
+----------------------------------------------------------------+
| [ 欄位 ] [ 工單型別 ]                                          |
+------------------+-----------------------------------------------+
| 欄位組            | StoryPoint    數字   單值  追蹤 可彙總:加總 |
| 基本   [系統]     | BranchName    文字   單值                   |
| 專案              | ExternalTool  布林   單值                   |
| 版控   選取態     | CommitNo      文字   單值                   |
| 品質              +-----------------------------------------------+
| [ 新增欄位組    ] | [ 新增欄位                                 ] |
+------------------+-----------------------------------------------+

頁籤：工單型別
+----------------------------------------------------------------+
| task   [系統]   基本、專案、版控                                |
| bug             基本、品質                                      |
| [ 新增工單型別                                                ] |
+----------------------------------------------------------------+
```

---

## 佈局

### 頁面工具列

- 分頁切換，欄位、工單型別兩項
- 當前分頁標示為選取態

### 欄位組清單

- 僅欄位分頁顯示
- 一列一個欄位組，顯示名稱
- **IF** 欄位組的 `system` 為真:
  - 顯示系統標示
  - 不顯示刪除入口
- 選取態標示當前檢視的欄位組
- 新增欄位組入口

### 欄位清單

- 僅欄位分頁顯示
- 資料為當前選取欄位組底下的欄位
- **IF** 尚未選取任何欄位組:
  - 顯示引導選取欄位組的提示
- **一列一個欄位:**
  - 識別名稱
  - 顯示名稱
  - 值型別
  - 欄位形狀，單值或多筆
  - **IF** 追蹤開關為真:
    - 顯示追蹤標示
  - **IF** 可彙總開關為真:
    - 顯示彙總算法
  - **IF** 欄位的 `system` 為真:
    - 顯示系統標示
    - 不顯示編輯與刪除入口
- 新增欄位入口

### 工單型別清單

- 僅工單型別分頁顯示
- **一列一個工單型別:**
  - 顯示名稱
  - **IF** 工單型別的 `system` 為真:
    - 顯示系統標示
  - 已勾選的欄位組名稱
  - 編輯配方入口
- 新增工單型別入口

---

## 互動

- **切換分頁:**
  - 內容區改呈現目標分頁

- **選取欄位組:**
  - 欄位清單改呈現該欄位組底下的欄位

- **新增欄位組:**
  - 填寫欄位組名稱
  - 呼叫 createFieldSetDef
  - **IF** 操作成功:
    - 新欄位組成為選取態

- **刪除欄位組:**
  - 呼叫 deleteFieldSetDef
  - **IF** 操作失敗:
    - 顯示禁止原因

- **新增欄位:**
  - 填寫識別名稱、顯示名稱、值型別、欄位形狀、追蹤開關、可彙總開關與彙總算法
  - 呼叫 createFieldDef

- **編輯欄位顯示名稱:**
  - 呼叫 updateFieldLabel

- **刪除欄位:**
  - 呼叫 deleteFieldDef
  - **IF** 操作失敗:
    - 顯示禁止原因

- **新增工單型別:**
  - 填寫識別名稱、顯示名稱、勾選欄位組
  - 呼叫 createIssueTypeDefinition

- **編輯工單型別配方:**
  - 調整欄位組勾選
  - 呼叫 updateIssueTypeFieldSets
